YouTube

Checking

Read your channel and videos. Apply approved metadata and schedule eligible private uploads through the official Data API.

  1. Deploy on a persistent HTTPS server with outbound Google access.
  2. Create your Google OAuth client and enable YouTube Data API v3.
  3. Use npm run youtube-token on your own computer and consent to channel access.
  4. Set the YouTube environment variables and restart the server.
